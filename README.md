# Emilex Stores

A modern and responsive boutique website created for **Emilex Stores**, a fashion store located at Jimeta Modern Market, Yola, Adamawa State, Nigeria.

The website provides customers with a simple way to explore fashion products, learn more about the store, and contact Emilex Stores directly through WhatsApp.

## Features

- Modern fashion-store interface
- Fully responsive design for mobile, tablet, and desktop
- Product showcase section
- Fashion categories
- Product prices
- Direct WhatsApp ordering
- Store information and contact section
- Floating WhatsApp button
- About Emilex Stores section
- Smooth navigation
- Modern dark design with bright accent colors

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## WhatsApp Ordering

Customers can select products and contact the store directly through WhatsApp.

The website automatically directs customers to the Emilex Stores WhatsApp number for product enquiries and orders.

## Purpose

This project was developed as a demonstration of how Emilex Stores could establish a professional online presence and make it easier for customers to discover products and contact the business.

Product names, prices and some images used in this demonstration may be placeholders and can be replaced with the store's actual inventory.
